## 01. Overview

This repository serves as a consolidated record of my hands-on learning and practical exploration in **RTL Design, Digital System Verification, ASIC Physical Design, and VLSI implementation**.

Organized across multiple training modules and project stages, it brings together practical exercises, design files, implementation workflows, observations, and supporting documentation from my learning journey.

Rather than treating each exercise as an isolated task, this repository provides a structured view of the concepts and workflows involved in digital hardware development—from describing hardware behavior in RTL to exploring synthesis, physical implementation, and timing analysis.

The repository is organized into four major learning areas:

- **RTL Design Modules:** Digital design concepts and RTL-related practical exercises.
- **Physical Design Modules:** Exploration of ASIC physical design concepts and implementation stages.
- **VSDBabySoC:** Practical work organized around different stages of the SoC design flow.
- **VSD VLSI:** Weekly learning activities, experiments, and technical exercises.

## 02. RTL Design — Modules 1 to 5

RTL (Register Transfer Level) design describes digital hardware in terms of data transfers, operations, and control behavior. It is an important starting point in the digital IC design process.

Across these five modules, I organize my RTL training exercises and related documentation to make the progression of practical work easy to explore.

### Learning focus

- Understanding digital hardware design and RTL descriptions.
- Exploring Verilog-based design concepts and coding practices.
- Working with simulation and functional verification concepts.
- Examining design behavior and debugging through practical exercises.
- Building a foundation for logic synthesis and downstream implementation.

## 03. ASIC Physical Design — PD Modules 1 to 5

Physical design transforms a synthesized logical design into a physical implementation while addressing constraints such as timing, area, connectivity, and manufacturability.

This part of my repository organizes practical work related to physical design concepts and the implementation flow. It provides a structured place to review the exercises, supporting files, and observations associated with each module.

### Learning focus

- Understanding the relationship between synthesis and physical implementation.
- Exploring floorplanning and design planning concepts.
- Studying placement, clock-related implementation, and routing concepts where covered.
- Understanding timing constraints and implementation reports.
- Developing familiarity with the tools and terminology used in ASIC physical design.

## 06. Tools & Technology Ecosystem

The following tools and technologies are relevant to the workflows documented in this repository. Their use varies by exercise and project stage.

| Tool / Technology | Purpose |
|---|---|
| Verilog HDL | Describing digital hardware at RTL |
| Icarus Verilog | RTL simulation |
| GTKWave | Inspecting simulation waveforms |
| Yosys | Logic synthesis and netlist generation |
| SKY130 PDK | Open-source process design kit and standard-cell technology |
| OpenSTA | Static timing analysis |
| Linux command-line tools | Running commands and managing design workflows |
| Git & GitHub | Version control and technical documentation |
