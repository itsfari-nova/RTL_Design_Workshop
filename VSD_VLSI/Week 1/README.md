# VSDIAT – 4 Weeks of VLSI Learning

> **From VLSI fundamentals to RTL simulation, synthesis and Gate-Level Simulation — a 4-week hands-on learning journey.**

---

## About This Repository

This repository contains my **4-week learning journey through VSDIAT sessions**.

During these sessions, I explored the fundamentals of **VLSI**, the complete **VLSI design flow**, RTL design using **Verilog**, simulation, synthesis, gate-level netlists, pre-synthesis and post-synthesis simulation.

The sessions also gave me hands-on experience with **GitHub Codespaces, VirtualBox, Linux commands, Icarus Verilog, GTKWave, Yosys and SKY130**.
